3 Things that I learned about HTML

Introduction

HTML which stands for HyperText Markup Language, is the standard markup language used to create and structure content on websites. It is one of the fundamental technologies of the World Wide Web and provides the basic structure that web browsers use to display information. Almost every website uses HTML in some form. When someone visits a website, a web browser such as Google Chrome, Microsoft Edge, Firefox, or Safari reads the HTML code and interprets it to determine how the content should be organized and displayed on the screen.

HTML is often used together with CSS and JavaScript. These three technologies have different but complementary purposes in web development. HTML provides the structure and content of the webpage. CSS, which stands for Cascading Style Sheets, controls its visual appearance, including colors, fonts, spacing, positioning, and layouts. JavaScript is a programming language that adds functionality and interactivity. For example, JavaScript can make menus open when users click buttons, validate information entered into forms, or dynamically update information without reloading the entire webpage.

HTML and the Structure

An easy way to understand these technologies is to imagine building a house. HTML represents the structure of the house, including its rooms, walls, doors, and windows. CSS represents the design and decoration, such as paint colors, furniture, and flooring. JavaScript represents functionality, such as lights turning on when a switch is pressed or a garage door opening when a button is activated. Together, these technologies allow developers to create functional and visually appealing websites.

HTML the Markup language

HTML is considered a markup language rather than a programming language because it primarily describes and organizes content instead of performing calculations or implementing complex programming logic. Nevertheless, learning HTML is an important first step for anyone interested in web development, software development, user experience design, or technical communication. Understanding HTML provides a strong foundation for learning CSS, JavaScript, web frameworks, accessibility, and other technologies used to build modern websites and web applications.

Three Things that I learned about HTML:

What is HTML Hypertext Markup Language:

  1. HTMLstands for HyperText Markup Language and is the standard markup language used to create webpages.

  2. HTML provides the basic structure of a website so that web browsers know how to display its content.

  3. HTML uses tags and elements to organize content such as text, images, links, headings, and lists.

What HTML Does:

  1. Structures web pages — HTML organizes content using headings, paragraphs, sections, lists, and other elements.

  2. Displays web content — HTML allows webpages to contain text, images, videos, tables, links, and other types of content.

  3. Creates links and navigation — HTML uses hyperlinks <a> to connect different webpages, sections of a website, or external websites.

How HTML Works:

  1. HTML uses tags and elements — HTML uses tags such as <h1>,<p> and <img> to tell the browser what type of content is on the webpage.

  2. The browser reads the HTML code — A web browser reads the HTML file and interprets its elements to determine how the webpage should be structured.

  3. The browser displays the webpage — After reading the HTML, the browser displays headings, paragraphs, images, links, lists, and other content for the user to see and interact with.

Conclusion

In conclusion, HTML is an important part of creating websites because it provides the basic structure and organization of a webpage. HTML uses tags and elements to create headings, paragraphs, images, links, lists, and other types of content. Web browsers read HTML code and display the information in a format that users can view and interact with. HTML can also work together with CSS to improve the appearance of a webpage and JavaScript to add functionality and interactivity. Learning HTML provides a strong foundation for understanding how websites are created and is an important first step for anyone interested in web development.
